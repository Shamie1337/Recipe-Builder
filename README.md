#  Recipe Builder

**Recipe Builder** е пълнофункционално уеб приложение за създаване и управление на кулинарни рецепти. 
Системата решава два основни проблема на домашния готвач: изчисляване на точната себестойност на ястието и проследяване на хранителните стойности (калории) чрез интеграция с глобални бази данни.

Приложението е разработено като курсов проект, използвайки **.NET 9 (Backend)** и **React + Vite (Frontend)**.

---

##  1. Как се пуска приложението

За да стартирате проекта локално, трябва да имате инсталирани:
* **.NET 8 SDK**
* **Node.js** (версия 16 или по-нова)
* **SQL Server** (LocalDB или SQL Express)

###  Стъпка 1: Настройка на Backend (Сървър)

1.  Отворете терминал в папката `RecipeBuilder.API`.
2.  Уверете се, че във файла `appsettings.json` connection string-ът (`DefaultConnection`) сочи към вашия SQL сървър.
3.  Изпълнете миграциите, за да създадете базата данни:
    ```bash
    dotnet restore
    dotnet ef database update
    ```
4.  Стартирайте сървъра:
    ```bash
    dotnet run
    ```
    *Сървърът ще стартира на адрес: `http://localhost:5182` (или подобен, според launchSettings).*

###  Стъпка 2: Настройка на Frontend (Клиент)

1.  Отворете нов терминал в папката на клиента (напр. `client` или `recipe-builder-client`).
2.  Инсталирайте необходимите библиотеки:
    ```bash
    npm install
    ```
3.  Стартирайте React приложението:
    ```bash
    npm run dev
    ```
4.  Отворете браузъра на адреса, изписан в терминала (обикновено `http://localhost:5173`).

##  2. Функционалности и как се използва

Приложението е разделено на логически модули за максимално удобство:

###  Автентикация и Сигурност
* **Регистрация:** Потребителят създава акаунт, след което получава 6-цифрен код за потвърждение на имейла си (чрез SMTP).
* **Google Login:** Възможност за бърз вход чрез Google OAuth2.
* **Сигурност:** Паролите се съхраняват хеширани, а достъпът до API-то е защитен.

###  Управление на Продукти (Ingredients)
* **Интелигентно търсене:** Интеграция с **Open Food Facts API**. Потребителят търси продукт по име (напр. "Nutella"), а системата автоматично попълва името и хранителните стойности (калории/протеини).
* **Хибриден модел:** Калориите се взима автоматично от външното API, но цената се въвежда ръчно от потребителя, за да е актуална за българския пазар.
* **Почистване:** Възможност за изтриване на продукти от базата.

###  Създаване на Рецепти
* **Калкулатор на себестойност:** При добавяне на продукт (напр. 200г Сирене), приложението автоматично смята колко стотинки струва това количество на база цената за килограм.
* **Нутриенти:** Автоматично сумиране на калориите за цялото ястие и визуализация в детайлен прозорец.
* **Many-to-Many връзка:** Един продукт може да участва в много рецепти с различни количества.

###  Списък за пазаруване & Любими
* **Shopping List:** Генериране на списък за пазаруване за конкретна рецепта с крайна цена.
* **Любими:** Потребителят може да маркира рецепти като "Любими" за бърз достъп.
